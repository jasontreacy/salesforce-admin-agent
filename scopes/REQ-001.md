## PLAIN ENGLISH

**What they're asking for.** Priya in wholesale ops keeps inheriting won deals with no note on
how the order gets to the retailer, and has to chase the rep. She wants a Fulfillment Method
dropdown on the opportunity that a rep has to fill in before marking the deal Closed Won.

**What's actually going on.** There is no fulfillment field at all today. The opportunity has
Order Channel (where the order came from) and Rush Order, which are different questions. Stages
are the Salesforce defaults; Closed Won is the only won stage, so "required when they close it"
has one clean trigger point.

**What it takes.** A new restricted picklist, one validation rule that fires only when the stage
is Closed Won and the field is blank, field access on the wholesale rep permission set, and a
slot on the Opportunity page layout. Settings changes, no code. Under an hour.

**What could go wrong.** The rule will also block anyone editing an *already-won* opportunity
that has no fulfillment method, including ops and admins fixing other fields. There are no
Closed Won opportunities in this org today, so that is a future-data question, not a migration.
The rule is written to fire only on Closed Won, so Closed Lost deals are untouched.

**What I'm not sure about.** Nothing blocking. Priya gave the three values; the field is not
required at creation, exactly as she asked.

## CONCEPT
Priya wants a Fulfillment Method picklist on Opportunity that must be filled before a deal is
marked Closed Won.

## TASKS
1. Create `Opportunity.Fulfillment_Method__c`, restricted picklist, values: Ship from Warehouse, Drop Ship from Vendor, Store Pickup. Not required at the field level.
2. Create validation rule `Fulfillment_Method_Required_When_Won` on Opportunity: `ISPICKVAL(StageName, "Closed Won") && ISPICKVAL(Fulfillment_Method__c, "")`, error on the Fulfillment Method field.
3. Grant read/edit on the new field in permission set `Lakeside_Wholesale_Rep`.
4. Add the field to `Opportunity Layout` in the Lakeside Order Details section.
5. Verify: a Closed Won save with the field blank is rejected; with a value it saves; a Closed Lost save with the field blank is accepted.

## CONSIDERATIONS
1. Editing any existing Closed Won opportunity will require a Fulfillment Method once the rule is live. The org has none today; on a real org, backfill before activating.

## OUTCOMES
1. An opportunity cannot be saved as Closed Won without a Fulfillment Method; every other stage saves as before.

## Delivery note
- Effort: under an hour of build, plus the check-only validation.
- Test in `lakeside-dev` only; this repo has no other target.
- The approver is deciding one thing: that blocking edits to fulfillment-less Closed Won deals is acceptable. Priya's request implies yes.
