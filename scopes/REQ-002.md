Marcus wants one more option in the Unqualified Reason dropdown on leads so reps stop
mis-filing price objections under "Went with Competitor". This is exactly as simple as it
sounds, with one thing worth knowing: the dropdown is backed by a shared value set

only the Lead field uses that set, so nothing else changes. The field is restricted and has no
controlling field, so there is no dependency to map. Nothing I am unsure about.
